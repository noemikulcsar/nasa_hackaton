CREW PHOTOS
===========

Drop your own photos in this folder. The console loads them by the file names below.
Until a file exists, the crew member's initials appear in the circle instead.

  astronaut_elena_voss.jpg
  astronaut_amara_okafor.jpg
  astronaut_lucas_marchetti.jpg
  astronaut_ravi_menon.jpg

To use a different name, change the "photo" field for that crew member in
src/data/database.json. Square photos (at least 400 x 400 px) look best.

Use only images you have the rights to use.
